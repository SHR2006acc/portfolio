# Mohamed Rayan Htalal Portfolio

A Vercel-ready Next.js 15 portfolio. Add the profile image to `public/images/profile.jpg` and the CV to `public/resume/Mohamed_Rayan_Htalal_CV.pdf`, then update the hero image in `components/portfolio.tsx`.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this folder in Vercel. No additional configuration is required.
